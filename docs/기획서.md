# MDD 프로젝트 기획서

## 1. 기획 배경

반도체 제조 공장(SK실트론)의 기계설비팀은 수십 종의 설비(냉동기, 냉각탑, 보일러, 공조기, 펌프 등)를 일 24시간 운전하며, 이에 따른 운전일지·점검일지·에너지 사용량·작업 지시서를 **담당자별 개인 PC의 엑셀 파일**로 분산 관리해 왔다.

이 방식은 다음과 같은 문제를 지속적으로 발생시켰다.

| 문제 | 상세 내용 |
|------|-----------|
| 데이터 분산 | 운전일지, 에너지, 작업지시서가 각기 다른 파일·PC에 저장 |
| 이력 추적 불가 | 담당자 교체 시 과거 데이터 인수인계 어려움 |
| 실시간 현황 파악 불가 | 현장 방문 또는 전화 없이 현재 설비 상태 확인 불가 |
| 에너지 분석 부재 | 유틸리티(LNG·스팀·질소·아르곤)별 사용 추이를 월간 집계 외 분석 수단 없음 |
| 작업 관리 비효율 | 수천 건의 Work Order를 엑셀로만 관리해 조회·필터·KPI 집계에 과도한 수작업 필요 |
| 이상 대응 지연 | 설비 이상 발생 시 현장 확인까지 시간 소요, 예방정비 계획 수립 어려움 |

이러한 문제를 해결하기 위해 **단일 웹 기반 통합 관리 플랫폼**의 필요성이 제기되었으며, 별도 서버 구축 없이 사내 PC에서 즉시 실행 가능한 로컬 배포형 대시보드 개발을 추진하게 되었다.

## 2. 기획 목적

### 2.1 핵심 목적
> **"기계설비팀의 모든 운영 데이터를 하나의 웹 화면에서 실시간으로 입력·조회·분석한다."**

### 2.2 세부 목적

**① 데이터 통합**
- 운전일지(냉동기·보일러·FFU·안전), 에너지 사용량, HMI 트렌드, 작업지시서를 단일 시스템으로 통합
- SQLite 기반 로컬 DB로 영구 저장 및 이력 관리

**② 실시간 모니터링**
- 전체 설비 상태(정상·주의·위험)를 대시보드에서 한눈에 파악
- 알람 발생·처리 현황을 긴급/고위험/경고/정보 등급으로 분류하여 즉시 인지

**③ 에너지 비용 관리**
- LNG·스팀·질소·아르곤 유틸리티별, 1·2·3공장별 일별 사용량 자동 집계
- 월 목표 예산 대비 실적 및 집행률 실시간 추적

**④ 작업 지시서(Work Order) 디지털화**
- 수천 건의 WO를 DB화하여 다중 조건 필터·페이징 조회 지원
- KPI(완료율·PM완료율·담당자별 현황) 자동 집계

**⑤ 예지 보전(AI 분석)**
- 설비 센서 데이터 기반 이상 패턴 감지 및 예방정비 권장
- 진동·압력·온도·차압 이상 탐지율 및 신뢰도 제공

**⑥ 배포 용이성**
- `python start.py` 한 줄 실행으로 서비스 기동
- 외부 클라우드·별도 DB 서버 없이 사내 PC에서 즉시 운영 가능

## 3. 기대 효과

### 3.1 운영 효율화

| 항목 | 기존 | 개선 후 | 효과 |
|------|------|---------|------|
| 운전일지 작성 | 개인 엑셀 파일 수작업 | 웹 UI 셀 입력 → 자동 저장 | 작성 시간 50% 단축 |
| 에너지 집계 | 월말 수작업 합산 | 엑셀 폴더 배치 → 자동 집계 | 집계 오류 제거 |
| WO 현황 파악 | 엑셀 필터 수작업 | 다중 필터 + 페이징 조회 | 조회 시간 80% 단축 |
| 설비 이상 감지 | 현장 순회 또는 전화 | 실시간 알람 대시보드 | 초기 대응 시간 단축 |
| 데이터 인수인계 | 파일 전달 + 구두 설명 | DB 이력 + 웹 조회 | 인수인계 누락 제거 |

### 3.2 비용 절감
- 에너지 예산 대비 집행률 실시간 모니터링으로 초과 사용 조기 감지
- 예지 보전 기반 예방정비로 설비 긴급 고장 및 부품 교체 비용 절감
- 부품 재고 현황 관리로 긴급 발주·과잉 재고 비용 최소화

### 3.3 품질 및 안전
- 냉동제조시설 안전점검표 디지털화로 점검 누락 방지
- 클린룸 환경(온도·습도·차압·파티클) 실시간 모니터링으로 공정 품질 리스크 조기 감지
- 알람 이력 DB화로 반복 고장 패턴 분석 및 근본 원인 제거

### 3.4 의사결정 지원
- 월별·연도별 에너지 트렌드 차트로 투자 우선순위 결정 근거 확보
- KPI 대시보드(완료율·PM완료율·담당자별 현황)로 팀 성과 가시화
- AI 예측 결과 기반 정기점검 계획 수립 지원

## 4. 기능 요약

### 4.1 메인 대시보드
- SK실트론 기계팀 전체 설비 운영 현황 한눈에 파악
- 설비 총 수·전체 가동률·알람 등급별 건수 KPI 카드
- 이번달 작업 현황(완료·진행 중·작성대기) 및 완료율 추이
- 최근 이상 알림 실시간 피드

### 4.2 실시간 모니터링
- 전체 설비 상태 분포(정상·주의·위험) 실시간 표시
- 설비별 클릭 시 상세 운전 데이터 조회
- 긴급·고위험·경고·정보 등급 알람 통합 관리
- 알람 확인·조치·완료 처리 이력 추적

### 4.3 설비 시스템
- 공조기(AHU) 운전 현황 및 공기처리 프로세스 데이터
- 냉동기·냉각탑·펌프(PCW·ICW) 계통 실시간 센서값
- 압력·유량·온도·진동·차압·전류 측정 포인트별 조회
- 냉매 사이클 계통도 시각화

### 4.4 냉동기·냉각탑 운전일지
- 연·월 선택 후 일별 설비 파라미터 셀 입력
- 냉동기(CH-01~CH-06), 냉각탑, 냉수·냉각수 펌프 파라미터 관리
- 점검자 기록, 단일 셀 저장 및 월 전체 일괄 저장(bulk) 지원
- SQLite 자동 저장 및 이전 데이터 조회

### 4.5 냉동기 가동 분석
- 월별 냉동기별 가동 전류·RT·가동률·가동시간 집계
- 연도별 추이 분석 차트(BarChart·LineChart)
- 전류값 입력 시 가동 상태 자동 집계

### 4.6 FFU 점검 일지
- Fan Filter Unit 일별 점검 항목 입력 및 입력률 현황
- 총 FFU 수 및 ERR률 집계
- 이상 항목 강조 표시

### 4.7 보일러 운전 일지
- 보일러 일별 운전 상태, 안전 점검 항목 입력
- 버너 안전연소·과열·급수장치·제어반 상태 기록
- 연소용 설비 운전 파라미터 저장

### 4.8 냉동제조시설 안전 점검표
- 안전관리 책임자·총괄자·안전관리원 기록
- 냉동기 냉매·오일·안전밸브·누설 감지 등 점검 항목
- 점검 결과 및 조치 내용 DB 저장

### 4.9 HMI 트렌드
- FAB·Process 선택 후 날짜별/범위별 조회
- 태그별 MAX·AVG·MIN 24시간 시계열 차트
- 알람 상한·하한선 표시, 범위 조회 시 일별 집계
- XLS 파일 자동 파싱 (TREND_YYYYMMDD.xls)

### 4.10 에너지 사용량
- LNG(도시가스)·스팀·질소·아르곤 × 1·2·3·신공장별 일별 사용량
- 월 사용량·월 사용금액·누적 사용량·예산 대비 집행률 KPI
- 공장별 일일예산·누적 추이 차트(ComposedChart)
- 에너지원별 비중 파이차트
- 엑셀 폴더 자동 스캔(5분 TTL 캐시), `?refresh=true`로 즉시 갱신

### 4.11 작업 보고 (Work Orders)
- 엑셀 업로드 또는 Work_Order/ 폴더 자동 스캔으로 DB 반영
- 다중 조건 필터(부서·작업유형·설비종류·위치·작업자·기간) + 페이징
- KPI: 전체·완료·진행중·작성대기·PM완료율
- 담당자별 작업 현황, 이번달 완료율 추이 차트
- WO 상태(확정·작성중·작성대기) 자동 정규화 및 집계

### 4.12 AI 분석·예지
- 설비 센서 데이터 기반 이상 패턴 자동 감지
- 진동·압력·온도·차압·유량 편차 예지 내용 및 조치 권장사항 제공
- 예측 정확도·신뢰도 표시
- 긴급·고위험·경고·주의 등급별 탐지 건수 집계
- 수소 누설·아르곤 밸브 고장·열교환기 효율 저하 등 예지 사례

### 4.13 클린룸 환경 모니터링
- 클린룸별 온도·습도·차압·파티클 실시간 데이터
- 위험·주의·정상 룸 분류 및 이상 감지 항목 표시
- 온도·습도·차압 추이 차트
- 공기조화 프로세스(급기온도·급기습도·급기풍량) 측정 포인트 조회

## 5. 기타 사항

### 5.1 개발 환경 및 제약
- **배포 환경**: 사내 인터넷 망 분리 환경, 외부 클라우드 사용 불가
- **운영 OS**: Windows PC (Python 3.10+ 설치 필요)
- **동시 사용자**: 최대 10명 이내 (SQLite 동시 쓰기 제한)
- **인증·권한**: 현재 미구현 — 사내 네트워크 내부 접근만 허용하는 것으로 보완
- **프론트엔드 소스**: 빌드 결과물(`dist/`)만 배포, 원본 소스 수정 시 별도 빌드 필요

### 5.2 데이터 관리 정책
- **SQLite DB** (`mdd_data.db`): 운전일지·작업지시서 영구 저장, git 제외 관리
- **엑셀 파일**: 에너지·HMI·작업보고서 원본, 폴더 구조로 버전 관리
- **백업**: DB 파일 주기적 복사 권장 (자동 백업 기능 미구현)
- **데이터 보존**: DB 삭제 없이 UPSERT 방식으로 항상 최신 데이터 유지

### 5.3 향후 개선 계획 (로드맵)

| 버전 | 주요 내용 |
|------|-----------|
| v1.1 | 로그인·권한 관리 기능 추가 |
| v1.2 | 에너지 예산 입력 기능 및 초과 알림 |
| v1.3 | 설비 이력 카드 (설비별 정비 이력 통합 조회) |
| v2.0 | PostgreSQL 전환 및 다중 사용자 동시 쓰기 지원 |
| v2.1 | 모바일 반응형 UI |
| v2.2 | 정기 보고서 자동 생성 및 PDF 출력 |

### 5.4 운영 담당
- **시스템 관리**: 기계설비팀 담당자
- **데이터 입력**: 각 설비 담당 운전원 및 기술담당
- **에너지 데이터**: 에너지 관리팀 (엑셀 파일 월별 폴더 등록)
- **작업지시서**: 설비관리팀 (WO 엑셀 업로드 또는 폴더 배치)
